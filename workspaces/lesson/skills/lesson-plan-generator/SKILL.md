# 教案生成与导出为 Word

## 何时使用

`workspaces/lesson/AGENTS.md` **工作流一（教案生成）阶段2 与阶段3** 使用。

- 阶段2 写 `tmp/lesson.md` 之前：**必须先读本文件**——本文件是「教案 Markdown 格式规范」的权威来源，AGENTS.md 只写了字段清单，细节以本文件为准。
- 阶段3：调用本技能脚本把 `tmp/lesson.md` 转成教案 Word。

通知、纪要、家长沟通不属于本技能，也不属于 lesson 身份。

## 教案 Markdown 格式规范（权威）

写入 `tmp/lesson.md` 时严格按以下结构。脚本 `scripts/convert_lesson.py` 按同一规范解析，
不符合规范的字段名会被当成普通段落，或在 stderr 上告警。

### 全文骨架

```markdown
# {单元名} 教案          ← 全文唯一的 `#` 总标题，只能有一个

## 单元教学设计

### 单元目标
### 学情分析
### 单元评价量规
### 实施计划        ← 必须是 Markdown 表格
### 学习活动
### 单元作业

## 第1课时 — {课题名称}（{课型}）
## 第2课时 — {课题名称}（{课型}）
...
```

### 硬性要求

1. **`#` 总标题全文唯一**。出现两个及以上，脚本告警 `检测到 N 个 # 总标题`。
2. **`## 单元教学设计` 必须存在**，且下列 6 个子字段一个都不能少（顺序建议照抄）：

   | 子字段 | 内容要求 | 推荐形式 |
   |---|---|---|
   | 单元目标 | 3~5 条，可测可评 | 有序列表 |
   | 学情分析 | 已有基础 + 可能困难 | 段落 |
   | 单元评价量规 | 维度 × 等级 | **表格** |
   | 实施计划 | 课时 / 课题 / 课型 / 要点 | **表格（必须）** |
   | 学习活动 | 单元级活动设计 | 无序列表 |
   | 单元作业 | 作业内容与量 | 段落或列表 |

3. **每个课时一个 `##` 标题，格式固定**：

   ```markdown
   ## 第N课时 — {课题名称}（{课型}）
   ```

   - `第N课时` 用阿拉伯数字，破折号用全角 `—`（脚本也接受 `-`）。
   - `（{课型}）` 用全角括号，如 `（新授课）`、`（复习课）`、`（练习课）`。
   - 命名按学科自适应：英语可附 Section 编号，其他学科直接用中文课题名。

4. **每个课时的 6 个字段一个都不能少**，字段名写成 `###` 三级标题：

   ```markdown
   ### 教学分析
   ### 学习目标
   ### 学习过程
   ### 设计意图
   ### 板书设计      ← 不能为空！
   ### 作业与拓展
   ```

5. **板书设计不能为空**。只写标题不写内容，脚本告警 `课时「…」的「板书设计」为空，必须补全`；
   整个字段缺失，脚本告警 `课时「…」缺少「板书设计」字段`。
   **产出 docx 前必须把告警清零**，缺内容就回去补 `tmp/lesson.md`。
6. `学习过程` 通常含**表格**或分步小标题（`#### 一、复习导入`）。两种都支持，可混用。

### 支持的 Markdown 语法

| 语法 | 转换结果 |
|---|---|
| `# 标题` | 居中放大加粗（教案总标题，18pt） |
| `## 标题` | 加粗（课时标题 14pt / 单元小节 12pt） |
| `### 标题` | 加粗（字段标题 12pt） |
| `#### 标题` | 加粗（学习过程分步小标题 11pt） |
| `**加粗**` | 行内加粗（同一段落内可混排） |
| `\| a \| b \|` 表格 | Word 表格（首行加粗居中，带边框） |
| `1. 有序项` | 编号列表，悬挂缩进 |
| `- 无序项` | 项目符号列表，悬挂缩进 |
| 空行 | 分段 |
| ```` ``` ```` 代码块 | 逐行等宽呈现（教案里尽量别用） |

表格分隔行 `|---|---|` 与 `| --- | :---: |` 都认。单元格里的 `**加粗**` 也会生效。
表格单元格内换行、合并单元格不支持。

### 排版结果（脚本固定行为）

- 页面 A4，上下页边距 2.54cm，左右 3.17cm。
- 正文：中文**宋体**（`w:eastAsia`）+ 西文 Times New Roman，五号字 **10.5pt**，**1.5 倍行距**，首行缩进 2 字符。
- 输出目录不存在时自动创建。

## 执行

```bash
python3 skills/lesson-plan-generator/scripts/convert_lesson.py \
  --input tmp/lesson.md \
  --output lessons/{单元名}_教案.docx
```

### 参数

| 参数 | 必填 | 默认 | 说明 |
|---|---|---|---|
| `--input` | 是 | — | 教案 Markdown 路径，通常 `tmp/lesson.md` |
| `--output` | 是 | — | 输出 docx 路径，通常 `lessons/{单元名}_教案.docx` |
| `--font-cjk` | 否 | `宋体` | 中文字体（同时写入 `w:eastAsia`） |
| `--font-latin` | 否 | `Times New Roman` | 西文字体 |
| `--body-size` | 否 | `10.5` | 正文字号，单位 pt（五号 = 10.5） |
| `--line-spacing` | 否 | `1.5` | 行距倍数 |
| `--no-warn` | 否 | 关 | 不打印格式告警（**不建议**，告警是质量闸门） |
| `--help` | 否 | — | 打印用法后退出 0 |

## 输出路径

- docx 落在 `lessons/` 下，文件名由 `--output` 决定，约定为 `{单元名}_教案.docx`。
- 脚本把**输出文件的绝对路径**打印到 stdout 第一行，随后打印相对路径与字数统计：

  ```
  /srv/openclaw-teacher/workspaces/lesson/lessons/第二单元_教案.docx
  已生成教案：/srv/openclaw-teacher/workspaces/lesson/lessons/第二单元_教案.docx（相对路径：lessons/第二单元_教案.docx）
  字数统计：318 字（中文字符 + 西文单词）；警告 0 条
  ```

- **不要**把该路径告诉老师：按 AGENTS.md「产出交付」先跑 `skills/obs-share` 上传换短链，
  给老师的只有「文件名 + 下载链接」。工作流一只需要这一个文件。

## 失败排查

| 现象 | 退出码 | 处理 |
|---|---|---|
| `错误：输入文件不存在：…` | 2 | 阶段2 还没写 `tmp/lesson.md`，或路径写错 |
| `错误：输入文件为空：…` | 2 | 重新生成 `tmp/lesson.md`；空文件会被拒绝 |
| `错误：输入文件不是 UTF-8 编码…` | 2 | 用 UTF-8 重写该文件（Windows 下别用 GBK 保存） |
| `错误：缺少依赖 python-docx` | 2 | 服务器依赖缺失，报给运维，**不要自己写解析代码替代** |
| `警告：课时「…」的「板书设计」为空` | 0 | 教案内容不合格：回阶段2 补板书设计后重跑 |
| `警告：课时标题「…」不符合 …规范` | 0 | `##` 标题没按 `第N课时 — 课题（课型）` 写，改 Markdown |
| `警告：缺少 # 总标题` / `检测到 N 个 # 总标题` | 0 | `tmp/lesson.md` 里 `#` 必须全文唯一 |
| `错误：写入 docx 失败：…` | 1 | 输出目录不可写或文件被 Word 打开占用，关掉 Word 再跑 |

- 退出码非 0 时**把 stderr 的错误原文贴给老师**，不要自己编造成功。
- 告警（退出码 0）不会阻止生成，但**板书设计缺失必须回去补**，不能直接交付。
