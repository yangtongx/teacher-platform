# 智能组卷（出题与 Markdown 格式规范）

## 何时使用

`workspaces/lesson/AGENTS.md` **工作流二（智能组卷与练习生成）阶段2** 使用。

老师提出「出一套试卷」「生成 10 道选择题」「帮我出期中考试卷」「出一套练习题」时，
走工作流二：确认需求 → 取素材 → **写 `tmp/exam.md` 与 `tmp/answer.md`（本文件）**
→ 转 Word（`skills/markdown-to-exam-docx/scripts/convert.py`）。

> **本技能只有格式规范，没有必用脚本。** 工作流二不依赖任何脚本也能完成：
> Markdown 由你按下面规范写出来，再交给 `markdown-to-exam-docx` 转换。
> `scripts/validate_exam.py` 是**可选质检工具，工作流不依赖它**。

## 阶段0：确认需求（缺必填项必须追问）

| 项目 | 必填 | 默认 |
|---|---|---|
| 学科 | 是 | — |
| 年级 | 是 | — |
| 考试范围 | 是 | — |
| 题量 / 题型偏好 | 否 | 按学科惯例 |
| 难度比例（易:中:难） | 否 | 3:5:2 |
| 考试时长 | 否 | 按题量估计 |
| 总分 | 否 | 100 分 |
| **英语学科：是否需要听力** | **必须追问** | 需要时听力占 20~30 分 |

不编造：教材版本、章节目录、课文内容、页码无法确认时先说「我无法确认」，
并要求老师提供范围；确认前不要产出题目正文。

## 第1步：题型分配参考

| 题型 | 适用学科 | 每题分值参考 |
|------|---------|------------|
| 选择题 | 通用 | 2~3 分 |
| 填空题 | 通用 | 2~3 分 |
| 简答题 | 语文、政治、历史 | 4~8 分 |
| 计算题 | 数学、物理、化学 | 8~15 分 |
| 实验题 | 物理、化学、生物 | 6~12 分 |
| 作文题 | 语文、英语 | 30~60 分 |

**分配完必须自己验算：各大题标注分值之和 = 各题分值之和 = 总分。**
例如「一、单项选择题（每题3分，共30分）」= 10 题 × 3 分。

## 第2步：`tmp/exam.md`（试卷版 / 学生版）格式

```markdown
# 八年级数学期中试卷（满分：100分 时间：90分钟）

姓名：__________　班级：__________　得分：__________

## 一、单项选择题（每题3分，共30分）

1.（3分）下列各数中，是无理数的是（  ）
A. 0.5　　B. √2　　C. 1/3　　D. -7

2.（3分）若 a > b，则下列不等式一定成立的是（  ）
A. a + 1 > b + 1　　B. a - 1 < b - 1　　C. -a > -b　　D. a² > b²

## 二、填空题（每题5分，共10分）

3.（5分）计算：(-2)³ = ___________。

4.（5分）若 x + 3 = 7，则 x = ___________。

## 三、解答题（每题15分，共60分）

5.（15分）解方程：2x + 5 = 17。

6.（15分）已知直角三角形两直角边分别为 3 和 4，求斜边长。
```

硬性规则：

1. `#` 一级标题 = **试卷名称**；建议写成 `{名称}（满分：X分 时间：Y分钟）`，
   转换脚本会把它拆成「标题 + 居中信息行」，质检脚本也据此核对总分。
2. `##` 二级标题 = **大题号**，格式 `## 一、单项选择题（每题3分，共30分）`。
   括号里**必须同时有每题分值与本题总分**，质检脚本靠它核对分值。
3. **选择题**：`1.（3分）题目内容（  ）`，括号里留两个空格给作答；选项 `A. ` `B. ` `C. ` `D. `
   **写在同一行**，中间用两个全角空格隔开，四个选项一个不能少。
4. **填空题**：`1.（2分）题目内容___________。`（下划线不少于 3 个）。
5. **计算/简答题**：`1.（10分）题目内容`。
6. **试卷版不标注难度等级**，更不能出现 `【答案】`/`【解析】`——
   转换脚本检测到答案标记会直接拒绝生成（退出码 3）。
7. 题干里不要写答案，不要用「（  ）」以外的答案位；图片题请在题干里写清图号并说明
   「图见试卷附页」，不要假造图片。

## 第3步：`tmp/answer.md`（答案版 / 教师版）格式

**包含完整题目（含所有选项）** + 答案 + 解题过程 + 难度标注：

```markdown
# 八年级数学期中试卷 参考答案

## 一、单项选择题（每题3分，共30分）

1.（3分）下列各数中，是无理数的是（  ）
A. 0.5　　B. √2　　C. 1/3　　D. -7

【答案】B
【难度】易
【解析】√2 是无限不循环小数，属无理数；0.5、1/3、-7 都是有理数。

## 二、填空题（每题5分，共10分）

3.（5分）计算：(-2)³ = ___________。

【答案】-8
【难度】易

## 三、解答题（每题15分，共60分）

5.（15分）解方程：2x + 5 = 17。

【答案】解：移项得 2x = 12，两边同除以 2 得 x = 6。
【难度】易
【解析】考查一元一次方程的解法：移项、合并同类项、系数化为 1。

8.（15分）某班有学生 40 人，其中男生比女生多 4 人，求男、女生各多少人。

【答案】解：设女生 x 人，则男生 (x + 4) 人，由 x + (x + 4) = 40 得 x = 18，男生 22 人。
【难度】中
【评分细则】设未知数 3 分，列方程 5 分，求解 4 分，作答 3 分。
```

硬性规则：

1. `#` / `##` 标题与试卷版**逐字一致**，题号顺序一一对应，数量必须相同。
2. **每题都要有完整题目和全部选项**，老师要能脱离试卷单看答案版。
3. 标记独立成行，按题型的固定顺序：

   | 题型 | 标记顺序 |
   |---|---|
   | 选择题 | 题目 + 选项 → `【答案】B` → `【难度】中` → `【解析】……` |
   | 填空题 | 题目 → `【答案】___答案___` → `【难度】易` |
   | 计算题 | 题目 → `【答案】解：步骤……` → `【难度】难` |
   | 简答题 | 题目 → `【答案】……` → `【难度】中` → `【评分细则】要点……` |

4. `【难度】` 只能取 `易` / `中` / `难`，且**整卷难度分布要贴近约定的比例**（默认 3:5:2）。
5. 计算题必须给完整步骤，答案必须验算过。

## 第4步：（仅英语听力）生成听力脚本

听力脚本格式与参数见 `skills/listening-audio-generator/SKILL.md`（执行前必须阅读）。
听力 MP3 输出到 `exams/{试卷名}_听力.mp3`。

## 输出路径

| 产物 | 路径 | 谁生成 |
|---|---|---|
| 学生版 Markdown | `tmp/exam.md` | 你（本技能规范） |
| 教师版 Markdown | `tmp/answer.md` | 你（本技能规范） |
| 听力脚本 | `tmp/listening_script.jsonl` | 你（仅英语听力） |
| 试卷版 Word | `exams/{试卷名}_试卷.docx` | `markdown-to-exam-docx` |

## 出题质量标准（AGENTS.md 原文）

- 知识点覆盖率 >= 80%
- 难度有梯度，不堆积同一难度
- 题目不照搬原题，基于已知题型变式
- 答案经过验算，计算题给出完整步骤
- 题目表述清晰无歧义
- 干扰项基于学生常见错误设计

补充的可操作判定：

| 质量项 | 可检查的做法 |
|---|---|
| 知识点覆盖率 | 逐题标注对应知识点，覆盖范围清单的 ≥ 80% |
| 难度梯度 | 易/中/难题目按 3:5:2 铺开，同一难度不连排 5 题以上 |
| 干扰项设计 | 每个错误选项对应一类典型错误（符号、单位、公式误用、概念混淆） |
| 无重复 | 同一知识点最多 2 题，且问法必须不同 |
| 分值自洽 | 各大题分值之和 = 总分；逐题分值之和 = 各大题分值之和 |
| 答案自洽 | 选择题答案在 A~D 内且唯一；填空题答案与题干空格数量匹配 |

## 可选质检工具（工作流不依赖它）

```bash
python3 skills/exam-generator/scripts/validate_exam.py \
  --exam tmp/exam.md --answer tmp/answer.md --total 100
```

机器可查 5 类问题，**有硬错误时退出码为 1**：

1. 题干数与答案数是否一致（含题号顺序）
2. 各大题标注分值之和是否等于总分（`--total` 或试卷名称里的「满分：X分」）
3. 有没有重复题干（忽略标点与括注后比对）
4. 选择题选项数是否完整（A~D 四个）
5. 学生版里是否误含 `【答案】`/`【难度】`/`【解析】` 等标记

| 参数 | 必填 | 说明 |
|---|---|---|
| `--exam` | 是 | 学生版 Markdown，如 `tmp/exam.md` |
| `--answer` | 否 | 教师版 Markdown；不给则跳过题量/答案比对 |
| `--total` | 否 | 期望总分；默认从试卷名称读取 |
| `--help` | 否 | 打印用法后退出 0 |

退出码：`0` = 无硬错误（可能有警告）；`1` = 有硬错误；`2` = 用法/文件错误。

## 失败排查

| 现象 | 处理 |
|---|---|
| 质检报「题干数与答案数不一致」 | 答案版漏了题：逐题核对 `tmp/answer.md`，补齐后重跑 |
| 质检报「各大题标注之和与总分不符」 | `##` 大题括号里的「共X分」或每题分值算错，重算总分 |
| 质检报「第 N 题缺选项：D」 | 选项没写全或没独立成行，补成 `D. ……` |
| 质检报「第 N 题与第 M 题题干重复」 | 变式改写题干（换情境/换数值/换问法） |
| 质检报「学生版里出现了答案标记」 | 试卷版必须纯净：把答案移到 `tmp/answer.md` |
| 转换脚本退出码 3（学生版出现答案标记） | 同上，改 `tmp/exam.md` 后重跑 |
| 老师给的教材版本/章节无法确认 | 明确说「我无法确认」，请老师提供范围，**不要编造** |
