# 文档解析（教材/教参 → 纯文本）

## 何时使用

- 老师上传了教材、教参的 PDF 或 DOCX，需要在后面的教案/出题流程里用到里面的内容时。
- 建 RAG 索引（`skills/rag/scripts/rag_index.py`）之前，必须先跑一次本脚本产出 txt。

**什么时候不要用**：

- 不要用本脚本解析试卷、通知、图片。它只处理带文字层的 PDF 与 Word。
- 不要用别的办法读 PDF。仓库红线写死了：**PDF 只能通过本脚本解析**，禁止直接读 PDF、
  禁止换 OCR 工具、禁止另写解析代码。

## 执行

契约调用方式（在**工作区根目录**下执行，即 `workspaces/lesson`）：

```bash
python3 skills/doc-parser/scripts/parse_doc.py uploads/{教材原文件名}.pdf
```

只传一个位置参数（原始文件路径）。文件名**必须保持老师给的原名**，禁止重命名。

## 输出路径

- 默认：`tmp/<原文件名>.txt`（原 basename 换扩展名）。
  例：`uploads/人教版数学七年级上册.pdf` → `tmp/人教版数学七年级上册.txt`。
- 需要用别的路径时加 `--output`：

```bash
python3 skills/doc-parser/scripts/parse_doc.py uploads/教材.pdf --output tmp/教材_v2.txt
```

`tmp/` 不存在时脚本会自动创建。

## 参数

| 参数 | 必填 | 说明 |
|------|------|------|
| `input` | 是 | 位置参数，待解析文件路径，支持 `.pdf` / `.docx` |
| `--output` | 否 | 输出 txt 路径，默认 `tmp/<原文件名>.txt` |
| `--max-size-mb` | 否 | 单文件大小上限，默认 `100`（MB），超过直接报错 |
| `--max-pages` | 否 | 页数上限，默认 `1000`；PDF 按页数，DOCX 按内容块（段落+表格行）数 |
| `--no-reflow` | 否 | 关闭 PDF 段落重排（默认**开启**，见下节）。只在需要"一行一行"的原始形态时用 |

## PDF 段落重排（默认开启，2026-09-17 追加）

**为什么默认开**：PDF 的文字层是**按行**排的，`get_text("text")` 出来的就是一行一行。
实测《义务教育教科书·语文八年级下册》（150 页）抽出 104,357 字符却有 **5,723 行、平均每行 16.7 字符**；
直接拿去切块会变成"一行一块" —— 切出 4,003 块、平均 24 字符/块（`chunk-size` 本该 700）。两个后果都实测到了：

| | 块数 | 平均块长 | 索引体积 | 索引/正文 | 检索命中 |
|---|---|---|---|---|---|
| 一行一块（旧行为） | 4,003 | 24 字符 | 2.23 MB | 7.83 倍 | `d 〔秩秩斯干（gān）幽幽南山〕语出《诗` —— 十几个字的碎片 |
| 重排成段落（现在） | 397 | 253 字符 | **0.99 MB（-56%）** | 3.55 倍 | 完整段落（含注释序号与释义），老师可直接用 |

规则（保守、可预测）：句末标点（`。！？…"』】）`）结尾的行 = 段落结束，否则与下一行**直接拼接**；
空行分段；`===== 第 N 页 =====` 标记行原样保留、不参与拼接（页码是引用依据）。

**注意**：抽出来的正文里常见**行首孤立字母**（`b。那时我的祖母…`、`d〔礼数〕礼节。`），
那是教材的**注释序号**（a、b、c…），是**真实内容**，不是解析错误 —— 不要试图"清洗"它们。

## 输出内容与成功提示

脚本把正文写进 txt，并往 stdout 打印（PDF 报「页数」，DOCX 报「块数」）：

```
解析页数：128
字符数：204531
段落重排：已启用（PDF 的视觉换行已合并成段落）
输出路径：tmp/教材.txt
```

- PDF：用 PyMuPDF（`fitz`）**逐页抽取**，页与页之间插入分隔标记
  `===== 第 N 页 =====`（RAG 建索引时靠这个标记记录来源页码）；随后**逐页**做段落重排
  （逐页是为了不跨页搬动文字，页码归属保持精确）。
- DOCX：用 `python-docx` **按正文顺序**抽段落与表格；表格每行转成
  `[表格] 单元格1 | 单元格2 | ...` 形式的一行文本；表格单元格里的段落不会被重复输出。
- 换行统一写 LF，文件末尾补一个换行。全程 `encoding="utf-8"`。
- 若有页面**没抽到文字**，stderr 会如实报出来：
  `注意：有 N 页没有抽到文字（共 M 页）。这些页多半是插图/扫描图，本脚本不做 OCR ——
  检索不会命中其中的内容`。这是为了暴露"正文页有文字层、部分页是扫描图"的混合体教材，
  否则老师会以为整本都入库了。


## 退出码与失败排查

| 退出码 | 含义 |
|--------|------|
| 0 | 成功 |
| 2 | 输入不合法：文件不存在、类型不支持、超过大小/页数上限、解析不出文字 |
| 3 | 缺少依赖：PyMuPDF 或 python-docx 没装 |
| 4 | 解析或写盘失败 |

常见失败与处理：

- `错误：输入文件不存在：...` → 先用 `ls uploads/` 确认文件名；红线规定 `uploads/`
  只允许 `ls` 看文件名，不要 `cat` 内容。
- `错误：不支持的文件类型：.doc` → 只支持 `.pdf` / `.docx`。老式 `.doc`、`.pptx`
  需要老师先另存为 PDF 或 docx。
- `错误：文件超过大小上限：...` → 单文件上限 100MB。请老师拆分后分册上传。
- `错误：PDF 页数超过上限：...` → 上限 1000 页。
- `错误：没有解析出任何文字：...` → 这是**扫描版（图片型）PDF**，没有文字层。
  本脚本不做 OCR，必须请老师提供带文字层的 PDF。
- `错误：无法打开 PDF（可能已损坏或加密）：...` → 请老师重新导出/解除密码保护。
- 退出码非 0 时，**把 stderr 原文贴给老师**，不要自己编造成功，也不要绕开脚本另找办法解析。

## 与其他技能的衔接

```
uploads/*.pdf  --parse_doc.py-->  tmp/*.txt  --rag_index.py-->  rag/*.db  --rag_query.py-->  教案素材
```

解析完接着建索引（详见 `skills/rag/SKILL.md`）：

```bash
python3 skills/rag/scripts/rag_index.py --input tmp/{教材原文件名}.txt \
  --db rag/textbook.db --source-file uploads/{教材原文件名}.pdf --smart
```

若 `tmp/{原文件名}.txt` 已存在，契约流程会直接复用它、不重复解析；只有内容确实变了
才需要重新跑 `parse_doc.py`（或先删掉旧的 txt）。
